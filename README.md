# hyzecompany/.github

- `profile/README.md` — página da organização no GitHub.
- `.github/workflows/` — workflows reutilizáveis de CI/CD (sites Astro, Workers, design system).
- `WORKSPACE.md` — guia geral do grupo para pessoas e agentes (mesmo conteúdo do `CLAUDE.md` do workspace).
- `workspace/` — arquivos da pasta-raiz local (`Documents\Desenvolvimentos\hyze`): guia, scripts
  `status` e `publicar-github`, e o `hyze.code-workspace` do VS Code. Para montar o workspace num
  PC novo: clone os repositórios lado a lado e copie estes arquivos para a pasta-mãe.
